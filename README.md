# Financial Data Table

This is a React-based application bootstrapped with [Create React App](https://github.com/facebook/create-react-app) to display data with sorting and filtering logic. The data is filterable by various parameters such as date, revenue, and net income. It also saves the selected filters in the local storage for a better user experience.

## Installation

To get the project up and running locally, follow the steps below:

### 1. Clone the Repository

```bash
git clone https://github.com/Serenablack/adv-table.git
cd adv-table
```

### 2. Install Dependencies

In the project directory, you can run:

```bash
npm install
```

### 3. Configure Environment Variables

Copy .env.example to .env and set the necessary environment variables, such as the API key to fetch financial data.

```bash
REACT_APP_API_KEY=your-api-key
```

### 4. Run Locally

Start the development server:

```bash
npm start
```

Visit http://localhost:3000 in your browser to view the app.
